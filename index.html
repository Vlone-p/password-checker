How does this work privately?
We use k-Anonymity. Your password is converted to a mathematical hash (SHA-1). Only the first 5 characters of that hash are sent to the HaveIBeenPwned API. The API returns a list of leaked passwords that start with those 5 characters. Your browser checks the rest locally. Your actual password never leaves your device.
