How does this work privately?
We use k-Anonymity. Your password is converted to a mathematical hash (SHA-1). Only the first 5 characters of that hash are sent to the HaveIBeenPwned API. The API returns a list of leaked hash suffixes and counts. Your browser compares the full local hash against these suffixes locally — your full hash (or password) is never sent to the service.
